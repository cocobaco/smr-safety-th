# แบบฟอร์มข่าวและข้อสังเกต
แม่แบบสำหรับผู้ดูแล — ไม่ใช่ข่าวที่ยืนยันแล้ว

- ชื่อเรื่อง:
- วันที่เกิดเหตุ/วันที่ข่าว:
- วันที่ตรวจแหล่ง:
- ประเภท: ข่าว / คำอธิบาย / บทวิเคราะห์ / แก้ไขข้อมูล
- แบบเตา/ประเทศไทย:
- หมวด IAEA ที่เกี่ยวข้อง:
- สถานะเอกสารต้นทาง:
- แหล่งอ้างอิงและตำแหน่ง:

## เกิดอะไรขึ้น
สรุปข้อเท็จจริงที่ตรวจแล้ว

## เกี่ยวกับความปลอดภัยอย่างไร
ระบุชัดว่าส่วนใดเป็นข้อสังเกตของผู้ดูแล

## ยังไม่ทราบอะไร
อธิบายผลของช่องว่างหลักฐานต่อข้อสรุป

## ติดตามต่อ
เอกสารหรือคำถามที่ช่วยลดช่องว่าง

## ประวัติแก้ไข
วันที่ / สิ่งที่แก้ / เหตุผล / แหล่งใหม่
