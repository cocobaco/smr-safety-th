# เกี่ยวกับแหล่งความรู้นี้
ฉบับเริ่มต้น · ทบทวน 30 ตุลาคม 2569

SMR Safety Thailand เป็นแหล่งความรู้ภาษาไทยที่ผู้ดูแลจัดทำเป็นการส่วนบุคคล สำหรับคนที่สนใจความปลอดภัย SMR และความเชื่อมโยงกับงานวิจัยของฝ่าย วป.
เป้าหมายคือช่วยให้ผู้อ่านตรวจสอบข้อมูล ตั้งคำถามได้ดีขึ้น และเห็นประเด็นวิจัยที่อยู่เบื้องหลังข่าว

เนื้อหาไม่ใช่ประกาศหรือจุดยืนอย่างเป็นทางการของ สทน. ไม่ใช้ตราหน่วยงานเพื่อสื่อว่าได้รับการรับรอง ทุกเรื่องที่เกี่ยวกับกิจกรรม ผลงานหรือบุคลากรของฝ่ายจะใช้เฉพาะข้อมูลที่อนุญาตให้นำเสนอสาธารณะ พร้อมระบุผู้มีส่วนร่วมตามหลักฐาน

แยกเนื้อหาเป็น:

- ข่าว/ข้อเท็จจริงจากแหล่งอ้างอิง
- คำอธิบายและบทวิเคราะห์ของผู้ดูแล
- คำถามวิจัยหรือประเด็นที่ยังไม่ทราบ

เมื่อพบข้อผิดพลาด ให้บันทึกสิ่งที่แก้ แหล่งข้อมูลใหม่ และวันที่แก้ ไม่ลบประวัติเพื่อทำให้ดูเหมือนไม่เคยมีปัญหา เสนอคำถามหรือแจ้งแก้ไขได้ที่ [GitHub Issues](https://github.com/cocobaco/smr-safety-th/issues)
การมีบทความเกี่ยวกับผู้พัฒนาหรือแบบเตาไม่ใช่การสนับสนุนผลิตภัณฑ์นั้น
