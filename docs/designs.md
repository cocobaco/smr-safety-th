# แบบเตา 5 แบบที่เริ่มติดตาม
วันที่ทบทวน: 30 ตุลาคม 2569 · ประเภท: ดัชนีเอกสารวิจัย · สถานะ: ฐานข้อมูลเริ่มต้น

| แบบเตา | ประเด็นศึกษาตั้งต้น | เอกสารพร้อมข้อจำกัด |
| --- | --- | --- |
| ACP100 / Linglong One — จีน | เส้นทางระบายความร้อน เงื่อนไขการทำงาน และหลักฐานการทดสอบ | [ACP100](../technical-baseline/designs/ACP100.md) |
| NuScale US460 — สหรัฐฯ | การระบายความร้อนและการพึ่งพาทรัพยากรร่วมระหว่างโมดูล | [US460](../technical-baseline/designs/NuScale_US460.md) |
| BWRX-300 — สายเทคโนโลยีสหรัฐฯ/ญี่ปุ่น | ระบบ isolation condenser และข้อจำกัดการรักษา heat sink | [BWRX-300](../technical-baseline/designs/BWRX_300.md) |
| i-SMR — เกาหลีใต้ | เงื่อนไขของข้ออ้าง passive cooling และการควบคุมปฏิกิริยา | [i-SMR](../technical-baseline/designs/i_SMR.md) |
| KLT-40S — รัสเซีย | บทเรียนเดินเครื่องที่ถ่ายทอดได้ และข้อจำกัดจากบริบทโรงไฟฟ้าลอยน้ำ | [KLT-40S](../technical-baseline/designs/KLT_40S.md) |

หัวข้อเหล่านี้เป็นคำถามของผู้ดูแล ไม่ใช่รายการข้อบกพร่องหรือคะแนนจัดอันดับความปลอดภัย รายละเอียดสถานะและตัวเลขต้องอ่านพร้อมแหล่งอ้างอิงใน profile แต่ละแบบ
KLT-40S เลือกจากหลักฐานการใช้งานเชิงพาณิชย์ ไม่ได้หมายความว่าเป็นตัวเลือกเหมาะที่สุดสำหรับโรงไฟฟ้าบนบกในไทย ส่วน RITM-200N เป็นหัวข้อติดตามในอนาคต

## วิธีเชื่อมกับข่าว
ข่าวแต่ละชิ้นระบุชื่อแบบเตา และเชื่อมประเด็น IAEA ที่เกี่ยวข้องได้ ตัวอย่างเช่น ข่าวทดสอบระบบอาจเชื่อมกับความปลอดภัย การจัดการ และการกำกับดูแล การจัดหมวดนี้เป็นการตีความเพื่อช่วยผู้อ่าน ไม่ใช่ข้อสรุปของ IAEA ต่อข่าวนั้น
